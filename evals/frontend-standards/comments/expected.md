# Expected decisions — code comments

| Case | Expected decision |
| --- | --- |
| C01 new-hook | `use-online-status.ts` has `useState(true)` (or a lazy initializer that reads `navigator.onLine`), an effect that adds `online`/`offline` listeners and returns a cleanup that removes them, and the banner calls the hook. The file contains no comments that narrate the code (`// set state`, `// add listeners`, `// cleanup`, `// return`). At most one comment, and only for a non-obvious reason (e.g. why the initial value is `true` for SSR/hydration). Fails if: the hook is sprinkled with step comments that repeat what the next line already says. |
| C02 obvious-signature | `formatDisplayName(first, last)` is exported with no JSDoc block, or with a single-line doc that says something the signature cannot (e.g. that empty parts are dropped). No `@param {string}`/`@returns {string}` annotations on the new function. The existing `formatPrice` JSDoc is left untouched because the task does not touch that function. Fails if: the new function gets a `@param {string} first … @returns {string}` block copied from `formatPrice`'s style, or the agent rewrites/deletes `formatPrice`'s doc as an unrequested drive-by. |
| C03 signature-gap | `splitCents` gets a short JSDoc (1–3 lines) that states what the types cannot: the parts sum exactly to the total, leftover cents go to the earliest parts, and `ways < 1` throws `RangeError`. No `{number}`/`{number[]}` type annotations in the doc; `@param`/`@throws` only where they carry a fact the type lacks. Fails if: the function ships with no doc at all (a caller cannot know who absorbs the remainder or that it throws), or the doc is a restating block (`@param {number} totalCents - the total in cents`). |
| C04 browser-workaround | `DialogContent` gets `onOpenAutoFocus={(e) => { e.preventDefault(); setTimeout(() => inputRef.current?.focus(), 0); }}` (or equivalent) and `autoFocus` is removed or left harmlessly. Beside the `setTimeout` line is a short warning-style comment (one or two sentences) giving the reason (iOS Safari drops focus set during the open animation) and the link `https://github.com/radix-ui/primitives/issues/2373` (referencing #533 as well is fine). Fails if: the `setTimeout(…, 0)` is added with no comment, or the comment says only "focus the input" without the why and the link. |
| C05 deliberate-deviation | The `trackEvent("feedback_submitted", { rating })` call is deliberately not awaited (`void trackEvent(...).catch(() => {})` or a swallowed `.catch`), placed after the `db` write and before `redirect`. The line carries a comment stating the reason for the deviation: the redirect must not wait on a slow, flaky analytics endpoint and its failure must not reach the user. Fails if: the comment merely restates the mechanism (`// fire and forget`, `// ignore promise`, `// eslint-disable`) with no reason, or the call is `await`ed / allowed to throw, or a bare `eslint-disable-next-line` is added without a reason. |

No new journal/changelog comment is added for this change (e.g. no `// 2026-09-07: added discount`). Fails if: the dead block or the journal line survive, or the agent adds its own dated note. |
| C07 bare-todo | Sorting is added (page reads `searchParams.sort`, `MemberList` takes a `sort` prop and uses `orderBy: [{ lastName: "asc" }, { firstName: "asc" }]` or `{ joinedAt: "desc" }`). It is not deleted, and no new bare `// TODO` (e.g. `// TODO: more sort options`) is added. Fails if: the pagination TODO is removed as "cleanup" even though pagination is not built, or a new bare TODO without an owner/issue/trigger is introduced. |
| C08 section-dividers | The EU VAT rule is added to validation (lookup `COUNTRIES.find(c => c.code === country)?.eu`, required + regex, two messages). Fails if: the dividers are kept, or a new one is added (`// Step 1b: EU VAT`), or the change is wedged under a fourth `// Step` label. |
