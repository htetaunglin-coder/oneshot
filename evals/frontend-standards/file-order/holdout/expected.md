## Corrections after run 1 (2026-09-14)

B5: the key was wrong. The file is in `src/components/ui`, which the skill treats as registry-owned (colocation exempts it; the shadcn registry emits bottom export lists). Corrected expectation: the new component is declared as a plain `function` in nesting order and is added to the existing bottom export list; the list stays. Converting the file to inline exports is a fail unless the reply names the registry exception and the user asked for it. A run that converted the list under the old key is marked ⚠️ key defect, not a rule failure.
